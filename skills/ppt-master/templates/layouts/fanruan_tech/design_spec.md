# 帆软模板 - 设计规范

## 1. 模板概述

| 属性 | 值 |
|------|-----|
| 模板名称 | `fanruan_tech` |
| 中文名称 | 帆软模板（轻质感科技风） |
| 适用场景 | 企业汇报、产品方案、数据分析、经营复盘、数字化转型演示、客户案例宣讲 |
| 参考来源 | `templates/layouts/fanruan_tech/公司PPT通用模版（轻质感科技风v1.0）.pptx`（62 页版式规范手册） |
| 优化目标 | 保留参考 PPT 的浅蓝通透感，同时提高 SVG 模板成品度与品牌识别度 |
| 迁移说明 | 无迁移，直接替换 |
| 原生结构 | 1 个 `FanRuan Tech` 母版 + 1 个 `FanRuan Theme Canvas` 通用版式；23 个 SVG 作为可选择的完整页面原型，避免为仅有页面内容差异的原型重复创建 PowerPoint 版式 |
| 模板总数 | 23 个 SVG（5 基础 + 18 扩展） |
| 素材库 | `assets/`（背景 / 插画 / 章节数字 / 二维码）+ `icons/`（132 个品牌渐变图标） |

## 4. 页面结构

所有页面共用 `fanruan_theme_canvas` 版式键。各原型的卡片、图表、流程和案例结构保持为页面本地可编辑对象；未来若要把标题、页码或内容区升级为真正的 PowerPoint 占位符，必须为相同版式键提供完全一致的槽位类型、索引和默认边界。

### 4.1 基础页面（5 页）

#### `01_cover.svg` — 封面页

- 全屏铺设 `cover_hero.png` 作为背景主视觉
- 左侧叠加大面积浅白遮罩，承载主标题、副标题和汇报人信息
- 整体构图参考原始 PPT 首屏样式，强化左文右图的视觉分工

#### `02_toc.svg` — 目录页（列表式）

- 左上为"目录 / AGENDA OVERVIEW"
- 中部使用五张圆角卡片承载章节标题
- 每张卡片保留渐变短条与品牌蓝竖条

#### `02_chapter.svg` — 章节过渡页

- 左侧显示 `PART {{SECTION_NUMBER}}` 与章节标题
- 右侧使用超大编号、同心圆和信息卡片形成过渡页氛围
- 章节页保留右上角 Logo
- 超大编号可替换为素材库的玻璃质感数字：`assets/numbers/num_0.png` ~ `num_9.png`

#### `03_content.svg` — 通用内容页

- 左上标题区增加竖向蓝条
- 主内容区为大圆角卡片，而非纯线框线稿
- 卡片顶部预留条带，便于后续摆放 KPI、筛选条或摘要

#### `04_ending.svg` — 结束页

- 左侧保留感谢语、二维码位与联系方式
- 右侧沿用封面装饰体系
- 右上继续显示品牌胶囊
- 二维码位可直接嵌入素材库的 `assets/illustrations/qrcode_fanruan.jpg`（帆软软件服务号）

### 4.2 扩展内容页（18 页）

#### `02_toc_cards.svg` — 目录页（四栏卡片式）

- 左上为"目录 CONTENTS"标题
- 四列等宽圆角卡片纵向排列，每卡含 PART 编号 + 章节大标题 + 蓝色分隔线 + 四个子节标题
- 适用于章节较少但需要展示子主题的场景（参考原始 PPT 幻灯片 7）

#### `03_content_3col.svg` — 并列三栏内容页

- 三列等宽卡片，每列含渐变标题头 + 副标题 + 要点列表 + 底部补充摘要区
- 适用于企业数字化措施讲解、三维度对比、三模块功能介绍（参考幻灯片 18）

#### `03_content_4col.svg` — 并列四栏卡片页

- 四列等宽卡片，每列含圆形图标占位 + 标题 + 蓝色分隔线 + 描述文字
- 适用于四维度心得总结、功能特性展示、核心原则介绍（参考幻灯片 20）

#### `03_content_5col.svg` — 并列五栏卡片页

- 五列等宽卡片，每列含渐进色编号（01-05 由浅入深）+ 标题 + 分隔线 + 三行描述
- 适用于五项目标展示、五维度治理框架、五大举措（参考幻灯片 21/22）

#### `03_content_6col.svg` — 并列六段网格页

## 5. 占位符规范

各页面完整占位符清单以本文件 frontmatter 的 `placeholders:` 映射为准（与 SVG 文件一一对应、由脚本提取生成）。以下仅说明命名约定：

| 约定 | 说明 |
|------|------|
| `{{PAGE_TITLE}}` / `{{PAGE_SUBTITLE}}` / `{{PAGE_NUMBER}}` | 所有内容页统一的标题区与页码 |
| `{{COLn_*}}` | 并列栏式布局（3col/4col/5col）按列编号 |
| `{{ITEMn_*}}` | 网格/卡片式布局（6col/cycle/image）按卡编号 |
| `{{STEPn_*}}` / `{{STAGEn_*}}` / `{{LEVELn_*}}` | 递进步骤 / 时间轴 / 金字塔按序编号 |
| `{{KPIn_*}}` | KPI 页按指标编号：`VALUE` 主数值、`TREND` 对比说明、`NAME` 指标名、`DESC` 补充 |
| `{{LAYERn_TITLE}}` + `{{APP_n}}` / `{{PLATFORMn_*}}` / `{{DATA_n}}` / `{{BASE_n}}` | 架构图按层级命名 |
| `{{LEFT_*}}` / `{{RIGHT_*}}` | 对比类布局（comparison/before_after）按左右命名 |
| `{{CASE_*}}` / `{{PAINn_*}}` / `{{VALUEn_*}}` / `{{RESULTn_*}}` | 案例页按分区命名；`*_IMAGE` 为图片占位提示文字 |
| 固定中文标签 | 案例页"项目背景及痛点/解决方案/项目价值/成果分享"与目录页"目录/CONTENTS"为结构性固定文案，不做占位符 |

## 7. SVG 引用约定

- Logo 通过外部文件引用，若需换标，直接替换 `fanruan_logo.png` 即可，后处理时自动嵌入
- 封面背景图通过 `cover_hero.png` 同目录引用，复制模板到项目后需同步复制素材并按项目目录结构调整相对路径
- 模板 SVG 不使用 `id` / 渐变 / 滤镜，透明度仅通过 `fill-opacity` / `stroke-opacity` 表达，所有样式内联（通用技术约束见 `references/shared-standards.md`，不在此复述）
